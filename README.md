# SENTRY

3D-сайт-презентация стартапа SENTRY: аппаратно-программного стража кибербезопасности для IoT-сетей малого бизнеса в Узбекистане.

Команда: Исаев Сардор (основатель), Умурзаков Азим (заместитель руководителя, разработчик).

## Как открыть

Это статический сайт без сборки: `index.html` и папка `assets/`. 3D работает через Three.js с CDN, поэтому сайт нужно открывать через локальный сервер, например:

```bash
python3 -m http.server 8765
```

и затем http://localhost:8765

Все цены на сайте ориентировочные.
